# 제주숲홍차 프로모션 홈페이지
- 실행: `index.html`을 브라우저로 열기. 이미지는 `assets/images/`(WebP 22개, background-pattern 제외).
- 이미지 교체: 같은 파일명으로 덮어쓰기. 공식 제품 사진은 `index.html`의 `PRODUCT SLOT` 주석 위치(HERO·SECTION 04)의 `src`만 변경.
- HERO(메인 화면): 정식품식 풀스크린 Ken Burns + 크로스페이드, 팜한농식 줄별 자막 연출을 참고해 재해석(참고 사이트의 실제 움직임은 직접 확인하지 못해 명세 기준으로 구현). 기존 안개 효과와 `.hero-mist*`, `.hero-product`는 제거됨.
- 슬라이드 이미지·문구·링크 수정: `script.js` 맨 위 `HERO_SLIDES` 배열만 수정(HTML 수정 불필요). 모바일 전용 이미지는 `mobile`, 초점은 `pos`.
- 타이밍 수정: 표시 시간 `HOLD`(초, script.js), 전환 시간 `--fade`, 확대율 `@keyframes kenburns`, 자막 지연 `HERO_SLIDES` 생성부의 `dl()` 값(0.3/0.5/0.8/1.2/1.5초).
- 컨트롤: 이전/다음, 01 / 03, 진행 바, 일시정지, 모바일 스와이프. 탭 비활성·HERO 화면 밖에서는 자동 정지, 모션 감소 설정에서는 자동재생 꺼짐.
- 이미지 로딩 실패 시에도 포레스트 그린 배경 위에 자막·CTA가 유지됩니다.
- 미검증: 실제 브라우저 렌더링·모바일 스와이프·콘솔 오류(이 환경에는 브라우저가 없어 JS 문법 검사만 수행).
